# Developer Portfolio Website

A polished, responsive static portfolio template built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server.

## Personalize before publishing

All work descriptions, skill chips, availability status, and the email address are examples. Replace them with accurate information about yourself. The example projects are intentionally labeled and do not claim to represent your work. Do not publish the placeholder email as a real contact address.

## Checks

- Open `index.html` and inspect desktop and mobile layouts.
- Use the navigation menu at a narrow viewport and test keyboard access.
- Check links and replace all template fields.
